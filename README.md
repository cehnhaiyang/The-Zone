The Zone — 无尽领域

AI 驱动的 Roguelike 生存恐怖桌面游戏。

序言：虚假的末日与真实的降临

世界并未在一天之内毁灭，这是一场被精心策划的「降临」。

起初，它只是晚间新闻里几则语焉不详的异象播报：某地爆发了狂躁症、局部地区出现无法消散的红色浓雾、夜空闪过不可直视的紫色光晕。民众在惶恐中囤积物资，社会秩序逐渐紧绷。直到那层名为“现实”的帷幕被彻底撕裂，整个世界陷入了未知、扭曲、不可名状的深渊之中。

人们以为这是宇宙级的天灾。但废墟之下掩藏的真相是：这并非天灾，而是一场名为 「阿斯克勒庇俄斯计划（Project Asclepius）」 的受控实验。

幕后黑手：深渊基金会 (The Abyss Foundation)

一个隐秘的全球性寡头组织——“深渊基金会”，在数年前截获了来自宇宙深处的某种“信号”与“物质”。他们没有将其视为威胁，而是视作进化的阶梯与终极的权力。

基金会用难以想象的巨额资金收买了各界高层、政要、军方将领与顶尖学者。他们在城市的各个角落建立秘密实验室，用底层民众进行活体污染实验，目的是在“不可名状之物”真正降临前，解析其力量。

当“降临日”不可逆转地到来时，知情的高层早已携带数以亿计的资金和物资，逃往了被称为「方舟」的绝对安全区。他们切断了对外的所有联络，关闭了防爆门，将地表上百亿的绝望民众，留作锚定“神明”降临的血肉祭品。

异变机制：血肉与无机的狂宴

深渊力量的入侵首先破坏的是人类的认知逻辑。直视那些暴露在红雾中的实体、阅读禁忌的符文，甚至只是倾听它们的声音，都会导致大脑结构的物理性改变（理智/Sanity 崩塌）。

更恐怖的是“融合现象”。在深渊引力场内，有机物与无机物的界限被打破。病人的脊椎会与金属病床完美生长在一起；士兵的血肉会与防弹衣、甚至是武器枪管发生畸形的共生；废弃建筑的墙壁会长出呼吸的肉膜与转动的眼球。这不仅是屠杀，更是对地球生态的强行“重写”。

唯一能让人类在这片区域（The Zone）中保持清醒的，只有基金会为“清理人（Cleaners）”开发的神经链接仪。这种设备能强制过滤视觉与听觉中的认知危害信号（以电量和 UI 乱码为代价），成为探索者们唯一的生命线。

核心禁区 (The Zones)

在这片荒芜领域中，存在着几个因极高浓度的深渊能量而畸变的核心节点：

圣伊丽莎白纪念医院 (St. Elizabeth's Memorial Hospital)
曾是声誉卓著的慈善医院，实则是基金会进行“星神提取物”临床注射的震中。高层卷款潜逃，富豪在 VIP 病房中爆体而亡。如今，自愿留守的护士长与被困的施工队，在充满肉体融合怪物与腐败医疗器械的废墟中，建立起绝望的最后防线。

铁锈前哨 (The Bunker)
军方的地下防空洞。军方高层拒绝完全受制于基金会，试图通过「铁壁计划」将外星变异组织武器化。实验以惨烈的失败告终，收容失效后，深层掩体被彻底锁死。如今，只剩下疯狂的自动防卫系统和在极低温中缓慢苏醒的生化畸变体。

烛火书斋 (The Archive)
并非物理实体，而是位于现实夹缝中的古老多维图书馆。这里收藏着深渊的真实历史与宇宙的终极悖论。书架上的活体典籍会咀嚼读者的思想，镜中的倒影会递出致命的手稿。时间在这里失去了意义。

踏入深渊的人们 (The Investigators)

玩家将扮演那些因各种原因没有登上“方舟”，却又在绝境中握住武器的幸存者：

Kael (调查员)：曾是基金会表面产业的王牌经纪人，因追查异常资金流向而窥见深渊。他头上那台赖以生存的二手神经链接仪，是从一名死去的组织“清理人”手里扒下来的。

Elara (护士)：圣伊丽莎白医院的护士长。在整个世界崩塌、所有医生逃亡时，她选择留下保护那些被遗弃的重症患者。

Aria (神秘学者)：前大学民俗学教授。因为探寻禁忌真理，右手坏死后被异星真菌“复活”。她用理智换取魔法，在疯狂的边缘起舞。

Barnes (老兵)：特种作战中士。代号「黑仪式」行动的唯一幸存者。他每天都在酒精和自责中挣扎，试图用刀刃向那些夺走他小队的怪物复仇。

Unit-734 (守护者)：半人半机械的改造体。记忆核心已被强制格式化，只剩下“保护无辜者”的底层协议。他是军方与基金会技术的悲剧产物。
